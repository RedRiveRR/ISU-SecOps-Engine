# Security Policy

## Supported Versions

Only the latest version of ISU-SecOps-Engine is currently supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.7.x   | :white_check_mark: |
| < 0.7   | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1. **Do not** open a public issue.
2. Send an email to `security@mert.dev` (example addressed) or open a private security advisory on GitHub.
3. Provide a detailed description of the vulnerability and steps to reproduce it.

We will acknowledge your report within 48 hours and provide a timeline for a fix.
